English infographic titled “8 Benchmarks for AI Agents,” grouped into three areas. Code and software engineering: Terminal-Bench 4.0 tests complex terminal tasks; FrontierCode v1.1 tests code correctness, quality and mergeability; CursorBench 4.0 tests ambiguous, multi-file coding tasks; DeepSWE v1.1 tests long-horizon software engineering. Computer use and business workflows: OSWorld 2.0 tests long workflows through computer interfaces; AutomationBench tests business workflows across simulated app APIs. Knowledge work and science: GDPval-AA v2.1 evaluates reports, slides and spreadsheets; Terminal-Bench-Science 0.1 tests scientific workflows with verifiable outputs. Takeaway: Match the benchmark to the work. Check the setup. Test on your own tasks.
