# 从平面动效到卫星相控阵样片：制作记录

新片《Steering without turning》长36秒，1920×1080，60fps，共2160帧，包含原创配乐和英文说明。主题只讲一件事：阵面不转动，改变阵元间相对相位，让主波束改变方向，再把这个机制放回卫星对地指向场景。

## 先看清参考片

用户补充的《芯片简史》是新的主要参考，不能与上一版路由动效混为一谈。研究目录保存原帖记录和实际视频。720p副本全片12543帧逐帧解码，约209.05秒；自动记录帧间RGB差、亮度、变化面积、边缘密度和音频窗口值。人工查看67个不同抽样帧，另用4张1080p关键帧复核文字与结构。

这里的“全帧分析”有明确边界：所有帧经过程序检查，不等于人工逐一看完12543张图。详细报告与CSV位于 research/frame-audit-zh.md 和 research/reference-all-frames.csv；联系表在同目录。

参考片最值得学习的是镜头的用途：手机→芯片内部、灯丝→整灯→电极、器件→阵列→设备。每一次推拉都揭示下一层关系。输入波形、器件和输出同屏出现时，文字不必承担整个解释。材质、厚度和遮挡说明结构，比泛用辉光更有效。参考中的强白闪、小字号以及镜头运动中的标签拖影不适合直接复制。

仅凭成片不能确认参考作者使用了什么软件。下面记录的是本项目实际实施的路线。

## 实际技术栈

| 层 | 工具 | 具体用途 |
|---|---|---|
| 三维 | Three.js 0.186.1 + React Three Fiber 9.8.1 | 卫星、阵面、层间结构、相机、灯光、主瓣及旁瓣曲线 |
| 时间轴 | Remotion 4.0.530 + React 19.2.0 | 2160帧时间控制、音轨、渲染 |
| 文字与数据 | HTML / SVG / Geist | 清晰字幕、相位波形、角度与层编号 |
| 音乐 | Python / NumPy | 原创100BPM器乐、段落转场声、立体声延迟 |
| 交付 | FFmpeg | 色彩范围和BT.709转换、响度增益、H.264/AAC封装 |

上一版是React/SVG平面路由图，适合说明网络路径；这次的问题需要物体厚度、遮挡、阵面局部和空间指向，因此增加真三维渲染。这个选择针对本片，不意味着某个工具对所有视频都最好。

## 六个镜头

| 时间 | 画面 | 解释任务 |
|---|---|---|
| 0–6秒 | 卫星全景，缓慢改变观察角度 | 先定位阵面 |
| 6–12秒 | 同一阵面的微距 | 识别重复阵元 |
| 12–18秒 | 阵面、馈电、结构背板分离 | 看见控制层，编号与实物对应 |
| 18–24秒 | 8阵元切片、相位波形、波前和方向图同步变化 | 从相位到主瓣方向的因果关系 |
| 24–30秒 | 卫星移动、地面终端固定 | 阵面保持姿态，波束指向随几何改变 |
| 30–36秒 | 回到卫星全景 | 收回到系统层面的理解 |

每段6秒恰好是100BPM下10拍。标题短暂进入，主体持续运动。画面保持LeoGuoLabs浅色视觉，不照搬参考片黑金和紫蓝色调。

## 用同一状态驱动画面与数字

所有对象由帧号计算。`shot=floor(frame/360)`，`localTime=(frame-shot×360)/60`。相机、层间距离、相位和指向都依赖这些纯函数，不累加上一帧状态。

阵列示例：8阵元、等幅、间距d=λ/2，θ从阵面法向+z向+x计正。采用exp(+iωt)、传播exp(−ikr)，相邻相位差为Δφ=−2π(d/λ)sinθ。因此+30°对应−90°相位阶差。所有阵元同时有效，不能画成逐个开关。

方向图计算理想阵列因子的幅度，保留旁瓣。360个相位镜头帧逐一扫描方向图，角度采样0.1°，主峰与指令差小于0.05°；另检查360个跟踪帧的主轴始终指向同一终端。它证明这段示意片内部一致，不证明真实天线或链路性能。

## 实际修订

1. 阵元被底板倒角遮挡：将贴片和馈线向局部z正方向移出表面，不能靠调亮掩盖几何错误。
2. 微距太阳翼遮字：改为阵面近景，沿用相同几何、配色和倾角保持识别。
3. 跟踪镜头与标题过近：降低画面、缩小正交相机放大率。
4. 终端原来悬在球面上方0.25单位：移动球面，使终端基座接触表面。
5. 30°终态旁的累计相位一度显示−179°/−269°：让变化在22秒达到精确终态，再停留供阅读。
6. 分层图和法线缺少对应关系：增加依三维投影定位的01/02/03和法向、角度标记。

首版关键帧保存在 evidence/first-pass/，未覆盖掉问题证据。英文文章按这些实际迭代更新。

## 声音与验收

音轨完全由代码合成，没有下载参考片音乐，也没有旁白。源WAV为48kHz、24-bit立体声，测得−20.16LUFS、−5.00dBTP，最后0.5秒静音，留出自然结束。它是剪辑音效，不代表太空中的实际声波。

最终导出检查写在 evidence/final-ffprobe.json、final-audio.json、math-validation.json 和 browser-playback.json；最终帧抽查来自交付MP4。完整项目保留源码、依赖锁、渲染脚本和原始记录。

复现命令见 README.md。当前机器的系统python3会触发未接受Xcode许可的错误，因此制作使用既有 `/Users/leoguo/.pyenv/shims/python3`；没有修改系统许可或替换系统Python。
