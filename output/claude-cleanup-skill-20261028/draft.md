Claude users on macOS: claude-cleanup is worth bookmarking for local maintenance.

It starts with a read-only audit, backs up ~/.claude and ~/.claude.json before changes, then moves allowlisted caches and logs to Trash after confirmation. Sessions, history, skills, and project data are protected.

Login resets are separate, optional actions. Run changes from Codex or a regular terminal; Claude Code itself is limited to audit mode.
