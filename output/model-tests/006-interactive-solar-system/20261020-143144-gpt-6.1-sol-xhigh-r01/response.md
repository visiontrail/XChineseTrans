# 首次完整结果

已完成 Orbit：一个无需依赖、可离线打开的交互式太阳系网页。

可通过行星列表或场景选择天体、查看资料、拖动旋转和倾斜视角、滚轮或双指缩放、切换俯视视角、暂停及调整时间速度，并切换轨道与标签。提供键盘操作和响应式布局。

入口：`artifacts/index.html`。直接在现代浏览器打开，或在 `artifacts/` 下运行 `python3 -m http.server 8766 --bind 127.0.0.1`。

此为示意模型：行星大小和距离经过压缩，轨道为圆形，初始位置并非真实星历。
