Gemini 4 Argon gives Google a stronger position in frontier AI, especially in professional workflows and long-context understanding.

In Google's published comparison, Argon leads GPT-6 Astra and Claude Opus 5.5 on financial research, legal research and drafting, business automation, and long-video understanding.

A few useful reference points, in the order Argon / Astra / Opus 5.5:
• DeepSWE v1.1: 77.9% / 74.1% / 74.2%
• AutomationBench: 51.3% / 41.4% / 42.5%†
• GraphWalks, 256k–1M tokens: 84.2% / 71.8% / 66.8%

The coding picture is mixed. Astra leads on FrontierSWE v2 and Terminal-Bench-Science; Opus 5.5 leads on Terminal-Bench 4.0 and PostTrainBench. On vulnerability patching in CWE-bench v1, Argon and Astra both score 68%, versus 67% for Opus.

The engineering examples are also interesting. Google reports that deployed Argon-driven optimizations freed over 300 TiB of data-center memory. In libgav1, agents replaced 32,000 lines of SIMD code in an existing Rust port with safe Rust that the compiler could vectorize, achieving 2.7× that port's speed with identical video output. Larger C/C++-to-Rust migrations are still undergoing automated and manual review before deployment.

Argon supports reasoning trajectories of up to 1M output tokens. Artificial Analysis tested this with Long Decode Continuation, which pauses and resumes long responses across follow-up API calls.

Announced API pricing is $2 input / $10 output per million tokens during the introductory period, then $4 / $20. That is 20% of Astra's token pricing at launch and 40% afterward, matching Opus 5.5's standard rates. Cached input is discounted 95%.

Token price alone does not determine task cost. Artificial Analysis measured Argon at $1.99 per Intelligence Index task during the promotion versus Astra's $3.26; Argon used substantially more output tokens.

Access is still limited to trusted cyber defenders through Fairwind. Paid API customers and Google AI Ultra subscribers are planned next, with no broad-release date announced.

These are published configurations with different effort settings and agent harnesses. Argon's Science result uses a longer verifier timeout, and LVBench uses different video sampling across models. Match the benchmark to your workload, then measure completed work and total cost.

† Fallback enabled: some tasks may be handled by other Claude models.
