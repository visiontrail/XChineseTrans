# Git, the AI-Native Way

这是基于上一版文章重新组织的英文 AI 原生版本：16 节、28 个可直接复制的提示词、11 张原创 Git/工作流程图解，以及 1 张新封面。

## 阅读与复用

- `article.html`：完整离线图文阅读版；含目录、提示词复制按钮、配图放大。图片已嵌入文件。
- `article.md` / `article.txt`：可编辑英文正文和纯文本。
- `prompt-library.md`：按正文顺序提取的 28 个提示词。
- `command-atlas.md`：操作目标、Git 命令含义、对应提示词与图解的索引。
- `images/`：12 张英文配图 PNG。
- `diagrams/`：11 张图解的独立 HTML、SVG 与可编辑布局数据；HTML 保留主题切换与图片导出。
- `alt-text.md`：图片顺序、ALT 描述与图注。
- `companion/field-notes/`：与正文一致的两页静态示例项目；README 也已改为提示词驱动。
- `image-prompts.json`：封面使用内置 ImageGen 的完整提示词与模式记录；命令图解使用原生 SVG 绘制。

正文让 AI 负责环境检查、文件修改、Git 操作、PR、自动化、部署检查及故障处理。提示词复用已知上下文，并要求返回实际观察结果。登录验证、Passkey 等必须由账户本人完成的环节保留明确交接。

## 验证记录

Git 的关键状态变化已在临时本地仓库验证，示例项目的成功与故意失败路径也已检查。阅读页另做桌面、手机宽度和交互检查。详细结果保存在工作目录的 `research/`。

这些验证覆盖图解与本地示例的行为，不代表每个提示词在每种 AI 工具上都已执行，也不代表已创建远端仓库、运行 GitHub 托管工作流或完成公网部署。

上一版位于相邻的 `github-field-guide/`，本次使用独立目录保留原稿。
