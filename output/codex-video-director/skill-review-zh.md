# Video Director Skill：中文审查说明

这是与文章分开的可复用 Skill。它提炼制作方法，不规定题材、风格、镜头数量、时长或渲染软件。

## 六步流程

1. **导演 Brief**：明确观众、核心感受或信息、内容范围、视觉方向和交付要求。
2. **分镜**：为每个镜头安排表达任务，确定构图、动作、文字、衔接和声音作用。
3. **共享时间线**：将镜头、相机、字幕和声音事件集中到一份时间定义；程序动画按帧推导状态。
4. **运动与声音**：根据表达需要安排预备、加速、错相与收稳；静音、音乐、旁白和音效均按 Brief 选择。
5. **检查修正**：查看真实渲染画面和关键运动片段，记录具体问题，修改后复查；必要时增加有意义的数值检查。
6. **成片验证**：检查实际编码文件和真实播放，并交付视频、可编辑项目及复现所需资源。

## 使用

将 ZIP 中的 `video-director` 文件夹放到 `~/.codex/skills/`。在能够加载该 Skill 的任务中输入 `$video-director`，再说明想制作的主题和要求。

本机已保存到 `/Users/leoguo/.codex/skills/video-director/`。正式 Skill 用英文编写，内容在 `video-director/SKILL.md`；这份中文说明用于审查其结构与边界。

## 附带工具

包含一个使用 Python 标准库和 FFmpeg/ffprobe 的可选检查器，可完整解码、读取元数据、比对时间清单、测量响度并抽取审片帧。脚本的通过结果只覆盖其实际检查项，不代表视觉质量、听感或全部交付要求通过。
