Rumors put Z.ai’s next GLM base model at 2.5–3.5T parameters, versus 744B for GLM-5.3. If accurate, that’s 3.4–4.7× the total parameter count.

GLM-5.3 already improved through post-training on the same base as 5.2. Pairing that work with a much larger base could make the next release interesting—especially if speed and cost hold up at scale.

Fable-class performance is still a prediction. The real payoff would be stronger coding agents you can afford to keep running.
