# Shot plan

Timing is generated from speech into `public/timeline.json`. Each shot has a 0.6 s voice lead-in and a brief exit hold.

1. **bottleneck — When code outruns the plumbing**: A 2,500 bar grows beside a >30,000 bar; then code packets queue at a narrow checkout gate. Voice carries the explanation; highlighted objects carry continuity.

2. **git — Your history. On your machine.**: A repository tree and timeline move from the server to one laptop; its network link dims while local history remains accessible. Voice carries the explanation; highlighted objects carry continuity.

3. **partial — You can take less.**: Three clearly distinct regions: history depth, object content, and working-tree directories. Voice carries the explanation; highlighted objects carry continuity.

4. **contract — Assume the server is reachable.**: The large client history collapses into a bounded object cache. History and merge functions move to the service. Voice carries the explanation; highlighted objects carry continuity.

5. **demand — A job needs one file.**: One highlighted parser object travels to a workspace; repeat request takes the short local path. Label as a conceptual example. Voice carries the explanation; highlighted objects carry continuity.

6. **api — Sometimes, just ask.**: One path carries a diff query and response. A second view reveals a compact changeset with two paths linked to blob objects. Voice carries the explanation; highlighted objects carry continuity.

7. **cache — Reuse at every layer.**: Job → node daemon → regional cache → server; successive return arrows demonstrate cache hits without claiming measured request percentages. Voice carries the explanation; highlighted objects carry continuity.

8. **results — Less infrastructure. More room for CI.**: Two separate denominators with no bar comparing unlike metrics: 200× smaller infrastructure; 25% CI CPU capacity gain. Voice carries the explanation; highlighted objects carry continuity.

9. **tradeoff — A different contract has a cost.**: Offline independence and online service reliance shown as explicit design choices. End with three practical questions. Voice carries the explanation; highlighted objects carry continuity.

10. **close — Follow the bottleneck.**: Five-stage pipeline; the focus moves from code to retrieval, then build/test/review; final takeaway holds for reading. Voice carries the explanation; highlighted objects carry continuity.
