## 事后观察

先检查交付是否为可实际操作的网页，再观察城市布局、比例、动态细节，以及模型如何表达“生命感”。记录它提供了哪些交互，是否自行加入居民、交通或环境变化，并区分装饰动画和实际状态变化；这些具体元素并非提示词的必选要求。

以上只用于观察，不随提示词发送，也不预设二维、三维或模拟引擎。演示时持续观察同一区域的变化；画面有运动不等于城市具有真实模拟逻辑。
