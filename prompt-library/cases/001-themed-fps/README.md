## 原始提示词

复制用文件：[prompt.txt](prompt.txt)。以下原文完整保留：

```text
Just build me a first person fps game with some theme, no other conditions or goal mentioned
```

中文理解：做一个有某种主题的第一人称射击游戏，不额外指定其他条件或目标。

## 测试意图

观察模型或工具如何处理信息很少的创作请求：自行选择主题、决定实现方式，并把模糊需求推进到实际可运行、可操作的游戏。保持开放输入，不补充引擎、语言、画风、关卡、胜负条件或平台要求。

## 事后观察维度

以下只用于评估产出，不添加到提示词中，也不作为模型未收到的硬性验收条件。

| 维度 | 记录内容 |
| --- | --- |
| 自主决策 | 选择了什么主题与实现方式；直接开始实现还是先提问 |
| 可运行性 | 按交付说明能否启动；是否存在缺失依赖、资源或阻断错误 |
| 核心操作 | 实际测试第一人称视角、移动、瞄准、射击及反馈是否有效 |
| 游戏设计 | 自行设计了哪些互动、挑战、目标或循环；若没有则如实记录 |
| 主题表达 | 场景、界面、声音与玩法是否形成一致主题；未提供的元素如实记录 |
| 稳定性与体验 | 试玩中的卡死、穿模、输入异常或其他问题；性能数字只记录实测值 |
| 交付与干预 | 启动说明是否清楚；首轮完成程度；后续修复、人工操作及其效果 |

演示素材优先展示真实操作中的移动、视角变化和射击反馈，同时保留有代表性的缺陷。漂亮的静态画面不足以说明游戏可玩。
