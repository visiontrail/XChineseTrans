## 事后观察

观察模型选择了什么乐器、操作是否直观、输入是否真的发声，以及视觉反馈和声音是否对应。按它提供的操作方式检查连续演奏、松开输入后的声音状态和异常噪声；若支持多音，再检查同时演奏。

以上只用于观察，不随提示词发送，也不指定乐器种类、音色或输入方式。演示须保留实际声音；只有动画或音频代码不能证明乐器可正常演奏。
